Privacy Policy

Pavelfdrk Channel Analytics · Effective July 10, 2026

This is a private, read-only analytics dashboard operated by Pavel Fedorenko for analysis of his own channel. It is not sold or offered as a public multi-user service.

1. Data we access

The application uses Google OAuth 2.0 and YouTube API Services. After the channel owner grants access, it requests only read-only permissions: youtube.readonly and yt-analytics.readonly.

  • Channel identity and public channel statistics.
  • Video identifiers, titles, descriptions, thumbnails, duration, status and public statistics.
  • Channel analytics such as views, watch time, average view duration, retention percentages and subscriber changes.
  • OAuth tokens required to maintain the authorized connection.

The application does not upload, edit or delete channel content and does not request access to passwords, payment information, private messages or contacts.

2. How data is used

Data is used only to display the owner's dashboard, calculate reporting summaries and identify content and publishing trends. Data is not used for advertising, profiling of third parties, resale or unrelated purposes.

3. Storage, refresh and deletion

OAuth tokens and synchronized reporting data are stored in access-controlled application storage. YouTube-sourced non-statistical data is refreshed or deleted within 30 days. The owner may request deletion at any time; the operator will delete stored OAuth credentials and synchronized YouTube data within 7 days of a verified request.

4. Sharing and security

Data is not sold or shared with advertisers or data brokers. It may be processed by Google Cloud solely to host and operate the application. Reasonable access controls, HTTPS transport and restricted credentials are used to protect the service.

5. Google and YouTube policies

Use of information received from YouTube APIs complies with the YouTube API Services Terms of Service and YouTube API Services Developer Policies. Google's handling of data is described in the Google Privacy Policy.

6. Revoke access

The channel owner can revoke the application's Google access at any time from Google Account permissions. Revocation prevents future API access. To request deletion of stored application data, email pashqafdrk@gmail.com.
